# ZAUM — блогеры

Адаптивный прототип сервиса для просмотра демонстрационной базы блогеров, размещений и показателей. Данные взяты из демонстрационной таблицы, приложенной к тестовому заданию, и хранятся локально в `src/data.json`.

## Запуск

```bash
npm install
npm run dev
npm test
npm run build
```

React, Vite, Tailwind CSS. Поиск и фильтры применяются к таблице, метрикам и аналитике. Нажмите строку, чтобы открыть карточку. Сортировка работает в текущей выборке.

## Метрики и ограничения

CPM = стоимость размещения / охват сторис × 1000, как в исходной таблице. Общий CPM рассчитывается как отношение суммарной стоимости к суммарному охвату, а не среднее CPM по строкам. Себестоимость товара показана отдельно и не включена в CPM. Все показатели, включая будущие размещения и бартер, отражают значения в демонстрационной таблице; это не финансовый отчёт и не фактическая эффективность кампаний. Ссылки example.com демонстрационные. Изменения записей, авторизация и серверное хранение не реализованы. Далее: импорт Excel, редактирование, история кампаний, права доступа и проверка фактических результатов.
